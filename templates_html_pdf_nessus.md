# Templates HTML para PDFs ejecutivo y técnico de Nessus

Se usaron dos templates Jinja2 renderizados a PDF con WeasyPrint.

### Template ejecutivo (`executive.html`)

```html
<!DOCTYPE html>
<html>
<head><meta charset="utf-8"><title>Executive Report - {{ scan_name }}</title>
<style>
  body { font-family: 'Segoe UI', Arial, sans-serif; font-size: 11pt; margin: 40px; color: #333; }
  h1 { color: #1a3a5c; border-bottom: 2px solid #1a3a5c; padding-bottom: 8px; }
  h2 { color: #2c5f8a; margin-top: 30px; }
  table { width: 100%; border-collapse: collapse; margin: 15px 0; }
  th, td { border: 1px solid #ccc; padding: 8px 12px; text-align: left; }
  th { background-color: #1a3a5c; color: #fff; }
  tr:nth-child(even) { background-color: #f4f6f9; }
  .severity-4 { background-color: #d9534f; color: #fff; font-weight: bold; text-align: center; }
  .severity-3 { background-color: #f0ad4e; color: #fff; font-weight: bold; text-align: center; }
  .severity-2 { background-color: #5bc0de; color: #fff; font-weight: bold; text-align: center; }
  .severity-1 { background-color: #f5f5f5; font-weight: bold; text-align: center; }
  .severity-0 { background-color: #e8e8e8; text-align: center; }
  .summary-box { display: flex; gap: 15px; margin: 20px 0; }
  .stat-card { flex: 1; padding: 15px; border-radius: 6px; text-align: center; color: #fff; }
  .stat-card.critical { background: #d9534f; }
  .stat-card.high { background: #f0ad4e; }
  .stat-card.medium { background: #5bc0de; }
  .stat-card.low { background: #777; }
  .stat-card.info { background: #999; }
  .stat-number { font-size: 28pt; font-weight: bold; }
  .stat-label { font-size: 10pt; text-transform: uppercase; }
  .footer { margin-top: 40px; font-size: 9pt; color: #999; text-align: center; border-top: 1px solid #ddd; padding-top: 10px; }
</style></head>
<body>
  <h1>Nessus {{ scan_type }} - Executive Summary</h1>
  <p><strong>Scan:</strong> {{ scan_name }}</p>
  <p><strong>Target:</strong> {{ hostname }}</p>
  <p><strong>Date:</strong> {{ scan_date }}</p>
  <p><strong>Status:</strong> {{ status }}</p>

  <h2>Vulnerability Summary</h2>
  <div class="summary-box">
    <div class="stat-card critical"><div class="stat-number">{{ critical }}</div><div class="stat-label">Critical</div></div>
    <div class="stat-card high"><div class="stat-number">{{ high }}</div><div class="stat-label">High</div></div>
    <div class="stat-card medium"><div class="stat-number">{{ medium }}</div><div class="stat-label">Medium</div></div>
    <div class="stat-card low"><div class="stat-number">{{ low }}</div><div class="stat-label">Low</div></div>
    <div class="stat-card info"><div class="stat-number">{{ info }}</div><div class="stat-label">Info</div></div>
  </div>

  <h2>Complete List of Vulnerabilities by Host</h2>
  <p><strong>Host:</strong> {{ hostname }} ({{ host_ip }})</p>
  <table>
    <tr><th>Severity</th><th>Vulnerability Name</th><th>Plugin ID</th></tr>
    {% for vuln in vulns_sorted %}
    <tr>
      <td class="severity-{{ vuln.severity }}">
        {% if vuln.severity == 4 %}Critical
        {% elif vuln.severity == 3 %}High
        {% elif vuln.severity == 2 %}Medium
        {% elif vuln.severity == 1 %}Low
        {% else %}Info{% endif %}
      </td>
      <td>{{ vuln.plugin_name }}</td>
      <td>{{ vuln.plugin_id }}</td>
    </tr>
    {% endfor %}
  </table>

  <div class="footer">Generated by Nessus Essentials API — {{ generation_date }}</div>
</body></html>
```

### Template técnico (`technical.html`)

```html
<!DOCTYPE html>
<html>
<head><meta charset="utf-8"><title>Technical Report - {{ scan_name }}</title>
<style>
  body { font-family: 'Segoe UI', Arial, sans-serif; font-size: 10pt; margin: 40px; color: #333; }
  h1 { color: #1a3a5c; border-bottom: 2px solid #1a3a5c; padding-bottom: 8px; }
  h2 { color: #2c5f8a; margin-top: 35px; border-bottom: 1px solid #ddd; padding-bottom: 5px; }
  h3 { color: #3a6a9a; margin-top: 25px; }
  table { width: 100%; border-collapse: collapse; margin: 12px 0; }
  th, td { border: 1px solid #ccc; padding: 6px 10px; text-align: left; }
  th { background-color: #1a3a5c; color: #fff; }
  tr:nth-child(even) { background-color: #f4f6f9; }
  .severity-critical { background: #d9534f; color: #fff; padding: 3px 8px; border-radius: 3px; font-weight: bold; }
  .severity-high { background: #f0ad4e; color: #fff; padding: 3px 8px; border-radius: 3px; font-weight: bold; }
  .severity-medium { background: #5bc0de; color: #fff; padding: 3px 8px; border-radius: 3px; font-weight: bold; }
  .severity-low { background: #777; color: #fff; padding: 3px 8px; border-radius: 3px; }
  .severity-info { background: #aaa; color: #fff; padding: 3px 8px; border-radius: 3px; }
  .vuln-card { border: 1px solid #ddd; border-radius: 5px; padding: 15px; margin: 15px 0; background: #fafafa; page-break-inside: avoid; }
  .vuln-card h3 { margin-top: 0; }
  .meta { font-size: 9pt; color: #666; }
  .label { font-weight: bold; color: #1a3a5c; }
  .plugin-output { background: #272822; color: #f8f8f2; padding: 10px; border-radius: 4px; font-family: monospace; font-size: 9pt; white-space: pre-wrap; overflow-x: auto; }
  .footer { margin-top: 40px; font-size: 9pt; color: #999; text-align: center; border-top: 1px solid #ddd; padding-top: 10px; }
</style></head>
<body>
  <h1>Nessus {{ scan_type }} - Technical Report</h1>
  <p><strong>Scan:</strong> {{ scan_name }}</p>
  <p><strong>Target:</strong> {{ hostname }} ({{ host_ip }})</p>
  <p><strong>Date:</strong> {{ scan_date }}</p>
  <p><strong>Total Vulnerabilities (excl. Info):</strong> {{ total_vulns }}</p>

  <h2>Detailed Vulnerabilities by Host</h2>

  {% for vuln in vulns %}
  <div class="vuln-card">
    <h3>{{ vuln.plugin_name }}</h3>
    <table>
      <tr><td class="label">Plugin ID</td><td>{{ vuln.plugin_id }}</td>
          <td class="label">Family</td><td>{{ vuln.family }}</td></tr>
      <tr><td class="label">Severity</td>
          <td><span class="severity-{{ vuln.severity_label|lower }}">{{ vuln.severity_label }}</span></td>
          <td class="label">CVSS v2</td><td>{{ vuln.cvss_base_score or 'N/A' }}</td></tr>
      {% if vuln.cvss3_base_score %}
      <tr><td class="label">CVSS v3</td><td>{{ vuln.cvss3_base_score }}</td>
          <td class="label">Risk Factor</td><td>{{ vuln.risk_factor }}</td></tr>
      {% endif %}
      {% if vuln.cve %}
      <tr><td class="label">CVE</td><td>{{ vuln.cve }}</td>
          <td class="label">CWE</td><td>{{ vuln.cwe or 'N/A' }}</td></tr>
      {% endif %}
      {% if vuln.exploit_available %}
      <tr><td class="label">Exploit Available</td><td colspan="3">{{ vuln.exploit_available }}</td></tr>
      {% endif %}
    </table>

    <p><span class="label">Synopsis:</span><br>{{ vuln.synopsis }}</p>
    <p><span class="label">Description:</span><br>{{ vuln.description }}</p>
    <p><span class="label">Solution:</span><br>{{ vuln.solution or 'No solution provided.' }}</p>

    {% if vuln.plugin_output %}
    <p><span class="label">Plugin Output:</span></p>
    <div class="plugin-output">{{ vuln.plugin_output }}</div>
    {% endif %}
  </div>
  {% endfor %}

  <div class="footer">Generated by Nessus Essentials API — {{ generation_date }}</div>
</body></html>
```
