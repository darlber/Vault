# Commit Final
Feat: Add "Keep Screen On" Setting and Apply to Session Screen  
  
This commit introduces a new "Keep Screen On" option in the settings and applies this preference to the workout session screen. It also makes minor UI adjustments to the Settings screen and improves the exercise deletion flow in the Session screen.  
  
**Key Changes:**  
  
- **Settings Screen (`Settings.kt`, `SettingsViewModel.kt`, `SettingsEvent.kt`):**  
    - Added a `Checkbox` to toggle the "Keep Screen On" preference.  
    - `SettingsViewModel` now:  
        - Inherits from `AndroidViewModel` to access `Application` context for SharedPreferences.  
        - Manages a `_keepScreenOn` `MutableStateFlow` to hold the preference state, initialized from SharedPreferences (`settings_prefs`, key `keep_screen_on`).  
        - Handles `SettingsEvent.ToggleKeepScreenOn` to update the StateFlow and persist the preference in SharedPreferences.  
        - Uses `collectLatest` for UI events.  
    - UI improvements:  
        - Added `Spacer`s for better layout.  
        - Changed "TODO: Export/Import Database" button texts to "Export/Import Database".  
        - Aligned content to `Arrangement.Top` and `Alignment.Start`.  
        - Removed preview for `SettingsDialogPreview`.  
  
- **Session Screen (`Session.kt`):**  
    - Now observes the `keepScreenOn` state from `SettingsViewModel`.  
    - Introduced a new composable `KeepScreenOnEffect(enabled: Boolean)` in `KeepScreenOnEffect.kt`.  
        - This `DisposableEffect` uses `LocalContext` to get the current Activity and adds or clears `WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON` based on the `enabled` parameter.  
    - `KeepScreenOnEffect` is called within `SessionScreen` to apply the user's preference.  
  
- **Session Exercise Handling (`SessionPreview.kt`):**  
    - When an exercise card is long-clicked (`onLongClick`):  
        - It now sets `deleteExerciseDialog.value = true` in addition to selecting the exercise via `SessionEvent.ExerciseSelected`. This streamlines the process of initiating exercise deletion.  
  
**Impact:**  
  
- Users can now choose to keep their device screen on during a workout session via a new setting.  
- The Session screen will respect this preference, preventing the screen from turning off automatically.  
- The Settings screen has a slightly improved layout and clearer button labels.  
- The user experience for deleting an exercise from a session is more direct, as the confirmation dialog appears immediately on long-press.
