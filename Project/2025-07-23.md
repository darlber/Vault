Desarrollo de una simple UI
[[2025-07-23#Home.kt v1.0|Home.kt v1.0]] Contiene una estructura básica.
Para hacer el programa más modular, tendremos que crear clases con diferentes elementos de la ui final como, las tarjetas, la barra de abajo con los botones, etc.

1. Creamos [[2025-07-23#UiState.kt|UiState.kt]]
	1. Este archivo define varias **clases de estado de la UI** que representan la información que se muestra en la interfaz de usuario de la aplicación **ExerLog**.
		Estas clases actúan como contenedores o modelos de datos que agrupan y estructuran la información necesaria para que la UI pueda mostrarla de manera clara y organizada.
2. [SessionCard.kt](#SessionCard.kt) será la carta que aparecerá en la UI
3. [[2025-07-23#Home.kt v1.2|Home.kt 1.2]] Separamos las cartas de la lógica principal. A través de *LazyColumn*, envolvemos en un wrapper la session card.
