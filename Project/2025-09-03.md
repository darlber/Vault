# Commit Final
Refactor: Update database population and image handling  
  
This commit refactors the database population mechanism to fetch exercise data and images from a remote GitHub repository. It introduces version checking, local caching for JSON and images, and updates the `ImagePopup` to load images from the local cache or fall back to a remote URL.  
  
**Key Changes:**  
  
- **`PopulateDatabaseCallback.kt`:**  
    - `checkAndPopulateDatabase()` (replaces `prepopulateDatabase`):  
        - Downloads `exercises_en.json` from a GitHub URL (`Constants.GITHUB_URL`).  
        - Falls back to a local cache (`Constants.CACHE_FILENAME`) if the download fails.  
        - Parses the JSON into an `ExercisesVersion` object (new data class).  
        - Compares the remote version with a locally stored version (`SharedPreferences`, key `Constants.VERSION_KEY`).  
        - If the remote version is newer:  
            - Inserts/updates exercises in the database.  
            - Updates the local version in `SharedPreferences`.  
            - Writes the downloaded JSON to the local cache.  
            - Downloads and caches exercise images from `Constants.BASE_IMAGE_URL` into `context.filesDir/exercises/`. Images are only downloaded if they don't already exist in the cache.  
        - Displays `Toast` messages to inform the user about the update status.  
    - `onCreate()` and `onOpen()` now call `checkAndPopulateDatabase()`.  
    - Added helper functions: `readCache()`, `writeCache()`, `downloadJsonFromGitHub()`, `downloadAndCacheImage()`.  
- **`ImagePopup.kt`:**  
    - Now accepts a `Context` parameter.  
    - When loading exercise images:  
        - Checks if the image file exists in the local cache (`context.filesDir/exercises/`).  
        - If it exists, loads the image from the local file path.  
        - Otherwise, constructs the image URL using `Constants.BASE_IMAGE_URL` and the image asset name.  
- **`ExerRepositoryImpl.kt`:**  
    - `clearDatabase()` now calls `populateDatabaseCallback.checkAndPopulateDatabase()` instead of `prepopulateDatabase()`.  
- **`ExercisePicker.kt`:**  
    - Passes `LocalContext.current` to `ImagePopup`.  
- **`ExercisesVersion.kt` (New File):**  
    - New data class to represent the structure of the downloaded JSON, containing a `version` (Int) and a list of `Exercise` objects.  
- **`Constants.kt`:**  
    - Added new constants:  
        - `BASE_IMAGE_URL`: Base URL for exercise images on GitHub.  
        - `GITHUB_URL`: URL for the `exercises_en.json` file on GitHub.  
        - `CACHE_FILENAME`: Filename for the local JSON cache.  
        - `VERSION_KEY`: SharedPreferences key for storing the local exercises version.  
  
**Impact:**  
  
- Enables dynamic updates of the exercise database and associated images from a remote source without requiring an app update.  
- Improves resilience by caching downloaded data locally, allowing the app to function offline or if the remote source is temporarily unavailable.  
- Ensures users have access to the latest exercise information and images.  
- `ImagePopup` now efficiently loads images from local cache first, reducing network requests.
