# Commit Final
feat: Add welcome card and user name flow  
  
Adds a personalized welcome card to the home screen that displays the user's name.  
  
Introduces a new user onboarding flow on the first launch:  
- A dialog prompts the user to accept the terms of conduct.  
- After acceptance, a second dialog asks for the user's name.  
  
The user's name is then stored and used for the welcome message. Also includes the Spanish translation for the terms of conduct.
