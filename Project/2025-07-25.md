# TipoSet v1.2
```kotlin
package com.example.exerlog.core  
  
import android.content.Context  
import androidx.annotation.StringRes  
import com.example.exerlog.R  
  
object TipoSet {  
    @StringRes  
    val WARMUP = R.string.tipo_warmup  
    @StringRes  
    val EASY = R.string.tipo_easy  
    @StringRes  
    val NORMAL = R.string.tipo_normal  
    @StringRes  
    val HARD = R.string.tipo_hard  
    @StringRes  
    val DROP = R.string.tipo_drop  
  
  
    private val order = listOf(WARMUP, EASY, NORMAL, HARD, DROP)  
  
    /** Devuelve el siguiente tipo como string traducido */  
    fun nextLabel(context: Context, currentLabel: String): String {  
        val currentIndex = order.indexOfFirst { context.getString(it).equals(currentLabel, ignoreCase = true) }  
        val nextIndex = if (currentIndex == -1) 0 else (currentIndex + 1) % order.size  
        return context.getString(order[nextIndex])  
    }  
  
    /** Devuelve el siguiente tipo como recurso ID */  
    @StringRes  
    fun nextRes(@StringRes current: Int): Int {  
        val currentIndex = order.indexOf(current)  
        val nextIndex = (currentIndex + 1) % order.size  
        return order[nextIndex]  
    }  
  
    /** Devuelve todos los tipos como lista de Strings traducidos */  
    fun allLabels(context: Context): List<String> = order.map { context.getString(it) }  
}
```
# NavHost.kt -> AppNavHost.kt
```kotlin
package com.example.android.january2022.ui  
  
import androidx.compose.runtime.Composable  
import androidx.navigation.NavHostController  
import androidx.navigation.compose.NavHost  
import androidx.navigation.compose.composable  
import com.example.exerlog.core.Routes  
import com.example.exerlog.ui.home.HomeScreen  
import com.example.exerlog.utils.UiEvent  
  
@Composable  
fun AppNavHost(  
    navController: NavHostController  
) {  
  
    NavHost(  
        navController = navController,  
        startDestination = Routes.HOME  
    ) {  
  
        composable(Routes.HOME) {  
            HomeScreen(  
                onNavigate = { navController.navigationEvent(event = it) },  
            )  
        }  
  
    }  
}  
  
private fun NavHostController.navigationEvent(event: UiEvent.Navigate) {}
```

# Commit Final
Refactor: Update theme and core components for i18n  
  
This commit introduces significant changes to the app's theme, core components, and prepares for internationalization (i18n).  
  
**Theme:**  
- Renamed `ExerLogTheme` to `AppTheme`.  
- Introduced comprehensive light, dark, medium-contrast, and high-contrast color schemes.  
- Added a `ColorFamily` data class for better color organization.  
- Removed default typography from `Type.kt` and introduced `AppTypography`.  
  
**Core Components:**  
- **`Equipment.kt`:**  
    - Changed `displayName` to `nameRes` (String resource ID) for localization.  
    - Updated `getAllEquipmentStrings` and `fromDisplayName` to accept `Context` for string retrieval.  
- **`MuscleGroup.kt`:**  
    - Changed `label` to a String resource ID for localization.  
    - Updated `fromLabel` and `getAllMuscleGroups` to accept `Context`.  
- **`TipoSet.kt`:**  
    - Constants (`WARMUP`, `EASY`, etc.) are now String resource IDs.  
    - Added `nextLabel` to get the translated string of the next type.  
    - Added `nextRes` to get the resource ID of the next type.  
    - Added `allLabels` to get a list of all translated type strings.  
  
**Database & Repository:**  
- `ExerDAO.kt`: `getSessionById` now returns `Flow<Session>`.  
- `ExerRepository.kt`: Insert methods (`insertExercise`, `insertSession`, `insertSessionExercise`, `insertSet`) now return `Long` (the ID of the inserted item).  
- `ExerRepositoryImpl.kt`: Temporarily disabled `turnTargetIntoMuscleGroups` in `getMuscleGroupsForSession` (marked with TODO).  
- `GymSet.kt`: `tipoSet` is now an `Int` (likely to store the String resource ID from `TipoSet`).  
  
**UI & Navigation:**  
- Introduced `UiEvent.kt` to handle various UI-related events (navigation, website opening, timer actions, file creation).  
- Added `AppNavHost.kt` to manage navigation using Jetpack Compose Navigation.  
- `HomeScreen.kt`:  
    - Now takes an `onNavigate` lambda that accepts `UiEvent.Navigate`.  
    - Updated preview to use `AppTheme`.  
- `MainActivity.kt`:  
    - Now uses `AppTheme`.  
    - Sets up `AppNavHost` with a `rememberNavController()`.  
    - Requests `POST_NOTIFICATIONS` permission on Android 13+.  
    - Enables edge-to-edge display.  
  
**Localization:**  
- Added `values-es/strings.xml` for Spanish translations of equipment, muscle groups, and set types.  
- Populated `values/strings.xml` with English strings for the same categories.  
  
**Other:**  
- Added a placeholder `TODO.kt` file in the `di` package.
