# Commit Final
Feat: Implement filter sheets for Exercise Picker  
  
This commit introduces bottom sheet dialogs for filtering exercises by muscle group and equipment in the `ExercisePickerScreen`.  
  
**Key Changes:**  
  
- **`ExercisePicker.kt`:**  
    - Integrated `ModalBottomSheetLayout` to display filter sheets.  
    - Added `MuscleSheet` and `EquipmentSheet` as content for the bottom sheet.  
    - Clicking filter chip icons now opens the respective bottom sheet.  
    - Keyboard is hidden when a sheet is shown.  
- **`ExerciseViewModel.kt`:**  
    - Added `_allEquipment` StateFlow to hold the list of all available equipment, fetched from the repository.  
    - `UiEvent.ShowImagePopup` now also hides the keyboard.  
- **`ExercisePickerPreview.kt` (UI Component):**  
    - Added new callback parameters `onMuscleFilterClick` and `onEquipmentFilterClick` for the filter chip icons.  
    - Updated filter chip icons (AccessibilityNew to FitnessCenter for muscle groups).  
    - Passed new filter click events from `ExercisePicker` to `ExercisePickerPreview`.  
- **`ExerDAO.kt` & `ExerRepository.kt` & `ExerRepositoryImpl.kt`:**  
    - Added `getAllEquipment(): Flow<List<String>>` to DAO and Repository to fetch a distinct list of equipment from the `EXERCISE` table.  
- **New UI Components:**  
    - **`MuscleButton.kt`:** A composable button used within the filter sheets to represent a selectable muscle or equipment. Animates color based on selection state.  
    - **`Sheet.kt`:** A generic composable for displaying a list of items (like muscles or equipment) in a grid within a bottom sheet. Includes a title and a "Deselect All" button.  
    - **`MuscleSheet.kt`:** A specialized `Sheet` for filtering by muscle groups. Uses `MuscleGroup.getAllMuscleGroups()`.  
    - **`EquipmentSheet.kt`:** A specialized `Sheet` for filtering by equipment.  
- **Modal Bottom Sheet Implementation (New Files):**  
    - **`ui/modalbottomsheet/ModalBottomSheet.kt`:** Custom implementation of ModalBottomSheetLayout, State, and related components. This appears to be a copy or adaptation of the Material library's modal bottom sheet.  
    - **`ui/modalbottomsheet/Swipeable.kt`:** Custom implementation for swipeable behavior, likely used by the modal bottom sheet. This also seems to be an adaptation from Material components.  
    - **`ui/modalbottomsheet/Strings.kt`:** Utility for providing localized strings for accessibility within the custom modal bottom sheet components.  
- **Deprecated/Removed:**  
    - `core/MuscleGroup.kt`: Enum commented out, with a TODO to delete. `MuscleSheet` now uses `MuscleGroup.getAllMuscleGroups()` which implies `MuscleGroup` itself has been changed or moved.  
    - `core/Equipment.kt`: Enum commented out, with a TODO to delete. `EquipmentSheet` and `ExerciseViewModel` now manage equipment as `List<String>`.  
    - `core/Constants.kt`: Removed `EXERCISES_NAME` constant.  
- **Minor:**  
    - `MainActivity.kt`: Added a TODO comment about capitalizing JSON and translation.  
  
**Impact:**  
  
- Users can now filter the exercise list by specific muscle groups and equipment using interactive bottom sheet dialogs.  
- Improved user experience by providing a more refined way to find exercises.  
- Refactored how muscle groups and equipment are handled, moving away from enums with string resources to likely data-driven lists.  
- Introduced custom modal bottom sheet components, potentially for more control or to address specific needs not met by the standard library components at the time.
