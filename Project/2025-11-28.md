# Commit Final
feat: Implement screen-specific tutorials  
  
This commit introduces a multi-faceted tutorial system that provides guidance on different screens of the application.  
  
Key changes include:  
  
*   **Tutorial Types**: Added `TutorialType` enum (`HOME`, `SESSION`, `EXERCISE_PICKER`) to differentiate tutorials for each major screen.  
*   **Contextual Content**: The `TutorialDialog` now displays specific steps and content based on the active `TutorialType`.  
*   **Trigger Points**: Added floating action buttons (FABs) with a help icon on the Session and Exercise Picker screens to allow users to manually trigger the respective tutorials.  
*   **ViewModel Logic**: The `TutorialViewModel` is updated to handle different tutorial types, each with its own total number of steps.  
*   **UI Integration**: Integrated the new tutorial logic into `Home.kt`, `Session.kt`, and `ExercisePicker.kt`.  
*   **State Management**: Renamed `TutorialSlate.kt` to `TutorialState.kt` for clarity and updated it to include the `tutorialType`.
