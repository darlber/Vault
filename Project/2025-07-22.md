# Converters.kt
Esta clase `Converters` define funciones para que Room pueda convertir tipos que no entiende nativamente (como `List<String>` o `LocalDateTime`) a tipos simples (como `String`) y viceversa, permitiendo almacenarlos y recuperarlos correctamente en la base de datos.
Room no sabe guardar directamente una lista (`List<String>`), pero con el convertidor:
	Cuando guardas `favoriteColors = listOf("red", "blue", "green")`, Room usará `fromList` para convertirlo en `"red|blue|green"` y almacenarlo en la tabla.
	
	Cuando lees ese dato, Room usará `fromString` para convertir `"red|blue|green"` de vuelta a `listOf("red", "blue", "green")`.  


```kotlin 
package com.example.exerlog.utils  
  
import androidx.room.TypeConverter  
import java.time.LocalDateTime  
  
class Converters {  
  
    @TypeConverter  
    fun fromString(source: String): List<String> {  
        return source.split("|")  
    }  
  
    @TypeConverter  
    fun fromList(source: List<String>): String {  
        return source.joinToString("|")  
    }  
  
    @TypeConverter  
    fun fromDateTime(source: LocalDateTime?): String {  
        return source?.toString() ?: ""  
    }  
  
    @TypeConverter  
    fun toDateTime(source: String?): LocalDateTime? {  
        return try {  
            LocalDateTime.parse(source)  
        } catch (e: Exception) {  
            null  
        }  
    }  
}
```
