# Converters.kt
Esta clase `Converters` define funciones para que Room pueda convertir tipos que no entiende nativamente (como `List<String>` o `LocalDateTime`) a tipos simples (como `String`) y viceversa, permitiendo almacenarlos y recuperarlos correctamente en la base de datos.
Room no sabe guardar directamente una lista (`List<String>`), pero con el convertidor:

	Cuando guardas `favoriteColors = listOf("red", "blue", "green")`, Room usará `fromList` para convertirlo en `"red|blue|green"` y almacenarlo en la tabla.
	
	Cuando lees ese dato, Room usará `fromString` para convertir `"red|blue|green"` de vuelta a `listOf("red", "blue", "green")`.  


```kotlin 
package com.example.exerlog.utils  
  
import androidx.room.TypeConverter  
import java.time.LocalDateTime  
  
class Converters {  
  
    @TypeConverter  
    fun fromString(source: String): List<String> {  
        return source.split("|")  
    }  
  
    @TypeConverter  
    fun fromList(source: List<String>): String {  
        return source.joinToString("|")  
    }  
  
    @TypeConverter  
    fun fromDateTime(source: LocalDateTime?): String {  
        return source?.toString() ?: ""  
    }  
  
    @TypeConverter  
    fun toDateTime(source: String?): LocalDateTime? {  
        return try {  
            LocalDateTime.parse(source)  
        } catch (e: Exception) {  
            null  
        }  
    }  
}
```
# Database.kt
- @Database guardará las entidades (tablas). 
- **autoMigrations:**  
    Ayuda a que cuando cambias la estructura de la base de datos (por ejemplo, agregas o quitas columnas) la app actualice la base sin que pierdas datos ni tengas que hacer migraciones manuales.
- **exportSchema:**  
    Le dice a Room que guarde un archivo con la “foto” de la estructura de tu base (el esquema). Esto sirve para revisar cambios, control de versiones y evitar errores al migrar.
 - Conectamos la Database al DAO. Esto **es la conexión entre la base de datos y el código que usas para leer o escribir datos.**
```kotlin
package com.example.exerlog.db;  
  
import androidx.room.Database  
import androidx.room.RoomDatabase  
import androidx.room.TypeConverters  
import com.example.exerlog.db.entities.ExerDAO  
import com.example.exerlog.db.entities.Exercise  
import com.example.exerlog.db.entities.GymSet  
import com.example.exerlog.db.entities.Session  
import com.example.exerlog.db.entities.SessionExercise  
import com.example.exerlog.utils.Converters  
  
@Database(  
    entities = [  
        Session::class,  
        Exercise::class,  
        SessionExercise::class,  
        GymSet::class  
    ],  
    autoMigrations = [  
    ],  
    version = 2, exportSchema = true  
)  
  
@TypeConverters(Converters::class)  
abstract class GymDatabase : RoomDatabase() {  
    /**  
     * Connects the database to the DAO.     */    
     abstract val dao: ExerDAO  
}
```

# Commit final:
	Data: Add DAO and constant objects  
	
	This commit introduces the `ExerDAO` for database operations and constant objects for `Equipment`, `MuscleGroup`, and `TipoSet`.  
	  
	- **ExerDAO.kt:** Defines the Data Access Object (DAO) for interacting with the database. It includes methods for inserting, querying, updating, and deleting `Session`, `Exercise`, `SessionExercise`, and `GymSet` entities. It also provides methods to retrieve all entities, specific entities by ID, and to clear tables.  
	- **Equipment.kt:** Provides a list of common gym equipment as constants and a function to retrieve all equipment types.  
	- **MuscleGroup.kt:** Defines constants for various muscle groups and a function to get all muscle groups.  
	- **TipoSet.kt:** Defines constants for different set types (e.g., Warmup, Normal, Drop) and provides a function to cycle through them.
