# Commit Final
feat: Refactor settings screen and add user profile  
  
This commit introduces a major redesign of the settings screen and adds user profile functionality.  
  
Key changes:  
- Redesigns the settings UI using Cards for better organization into "Profile", "Screen", "Backups", and "Danger Zone" sections.  
- Adds the ability for users to set and edit their username, which is saved in user preferences.  
- Refactors the initial app launch flow to correctly handle showing the name input dialog once.  
- Adds confirmation dialogs for critical actions like deleting the database.  
- Removes the "Check for updates" button and related logic from the home screen.  
- Updates string resources for the new UI elements and dialogs.
