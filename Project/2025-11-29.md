# Commit Final
feat: Implement database import/export  
  
This commit introduces functionality for exporting and importing the application's database as a ZIP archive.  
  
Key changes include:  
*   Adding `import/export` logic to `SettingsViewModel` to handle zipping and unzipping of the database files (`mys_db`, `mys_db-wal`, `mys_db-shm`).  
*   Implementing a `closeDatabase()` method in the repository to safely handle the database connection during these operations.  
*   Updating the Settings screen to use the correct MIME type (`application/zip`) for the file pickers.  
*   Navigating to the home screen after a successful import to ensure the database is re-injected correctly.  
*   Updating dependencies, including a Kotlin version downgrade and adding the `sqlite-ktx` library.  
*   Replacing deprecated `hiltViewModel` and `Divider` imports with their current counterparts.
