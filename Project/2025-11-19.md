# Commit Final
feat: Enhance exercise statistics  
  
This commit introduces a significant enhancement to the exercise statistics feature.  
  
- **New DAO Queries**: Adds two new, more efficient queries (`getExerciseStats` and `getExerciseHistory`) to fetch aggregated exercise statistics (max weight, total volume, sets) and detailed history directly from the database.  
- **Improved Stats Popup**: The statistics popup now displays a more comprehensive graph with options to toggle between "Max Weight" and "Total Volume". It also includes the exercise name and a summary of key metrics like best weight, best volume, and total sessions.  
- **ViewModel and Repository Updates**: The `ExerciseViewModel` and repository layer are updated to use the new DAO queries, simplifying the logic for fetching stats.  
- **Data Entities**: Introduces `ExerciseStats` and `ExerciseHistory` data classes to model the results from the new queries.  
- **Type Converters**: Adds a Room `TypeConverter` for `LocalDate`.
