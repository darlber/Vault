# Commit Final
Refactor: Implement dynamic language switching for exercises  
  
This commit introduces dynamic language switching for exercise data based on the device's current language setting. The `ExercisePicker` now observes the device language and triggers a data refresh if it changes.  
  
**Key Changes:**  
  
- **`ExerRepository.kt` & `ExerRepositoryImpl.kt`:**  
    - Added `currentLanguage: Flow<String>` to expose the currently selected language for exercises.  
    - Added `getExercisesFlow(): Flow<List<Exercise>>` which emits exercises based on the `currentLanguage`.  
    - Added `switchLanguage(lang: String)` function to change the active language and trigger a database repopulation for that language.  
    - `ExerRepositoryImpl` now manages a `_currentLanguage` StateFlow, initialized with the device's current language.  
    - When `switchLanguage` is called and the language is different, it calls `populateDatabaseCallback.checkAndPopulateDatabase(lang)` and updates `_currentLanguage`.  
    - `clearDatabase()` in `ExerRepositoryImpl` now uses the `_currentLanguage.value` when repopulating.  
  
- **`ExerciseViewModel.kt`:**  
    - Now uses `repo.getExercisesFlow()` for `filteredExercises` to get exercises dynamically based on the current language.  
    - Added `changeLanguage(lang: String)` function which calls `repo.switchLanguage(lang)`.  
  
- **`ExercisePicker.kt`:**  
    - Gets the current device language from `LocalConfiguration.current.locales[0].language`.  
    - Uses a `LaunchedEffect(currentDeviceLang)` to call `viewModel.changeLanguage(currentDeviceLang)` when the device language changes. This ensures the exercise data is updated to the new language.  
  
- **`PopulateDatabaseCallback.kt`:**  
    - `checkAndPopulateDatabase(lang: String)` now always clears existing exercises (`exerciseDaoProvider.get().clearExercises()`) before inserting new ones for the specified language. This ensures that only exercises for the current language are present.  
    - Made `prefetchAllLanguages()` and `getCurrentLanguage()` public to be used by `ExerRepositoryImpl`.  
    - Minor logging message changes (e.g., "No JSON disponible" instead of "No JSON available").  
  
**Impact:**  
  
- Exercise names and details will now be displayed in the user's device language (if supported, defaults to English).  
- The exercise list automatically updates if the user changes their device language while the app is running.  
- The database population logic now ensures that only exercises for the currently selected language are stored, preventing data from multiple languages from coexisting.
