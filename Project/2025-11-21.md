# Commit Final
Refactor: Internationalize UI and clean up code  
  
This commit focuses on internationalizing the application by externalizing hardcoded strings into resource files for English and Spanish.  
  
Key changes include:  
- Replaced hardcoded text in Composables and classes with `stringResource()`.  
- Added a comprehensive `values-es/strings.xml` for Spanish translations.  
- Updated `values/strings.xml` with new keys for localization.  
- Cleaned up code by removing unused imports, comments, and unnecessary logic.  
- Updated `AndroidManifest.xml` for foreground service compatibility with Android 14.
