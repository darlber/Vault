# MainActivity
```kotlin
package com.example.exerlog  
  
import android.Manifest  
import android.os.Build  
import android.os.Bundle  
import androidx.activity.ComponentActivity  
import androidx.activity.compose.setContent  
import androidx.compose.material3.Surface  
import androidx.core.app.ActivityCompat  
import androidx.core.view.WindowCompat  
import androidx.core.view.WindowInsetsCompat  
import androidx.core.view.WindowInsetsControllerCompat  
import androidx.navigation.compose.rememberNavController  
import com.example.compose.AppTheme  
import com.example.exerlog.db.ExerDAO  
import com.example.exerlog.ui.AppNavHost  
import dagger.hilt.android.AndroidEntryPoint  
import timber.log.Timber  
import timber.log.Timber.DebugTree  
import javax.inject.Inject  
  
  
// Anotación para habilitar la inyección de dependencias con Hilt en esta actividad  
@AndroidEntryPoint  
class MainActivity : ComponentActivity() {  
    @Inject  
    lateinit var dao: ExerDAO  
  
    override fun onCreate(savedInstanceState: Bundle?) {  
        super.onCreate(savedInstanceState)  
  
        WindowCompat.setDecorFitsSystemWindows(window, false)  
  
        if (BuildConfig.DEBUG) {  
            Timber.plant(DebugTree())  
        }  
        // Hide the status and navigation bars  
        val windowInsetsController = WindowCompat.getInsetsController(window, window.decorView)  
        windowInsetsController.systemBarsBehavior =  
            WindowInsetsControllerCompat.BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE  
        windowInsetsController.hide(WindowInsetsCompat.Type.systemBars())  
  
  
        setContent {  
            AppTheme {  
                if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU) {  
                    ActivityCompat.requestPermissions(  
                        this, arrayOf(Manifest.permission.POST_NOTIFICATIONS), 0  
                    )  
                }  
                // Permitir que el contenido ocupe toda la pantalla  
  
                // Controlador de navegación                val navController = rememberNavController()  
                Surface {  
                    AppNavHost(navController = navController)  
                }  
            }  
  
        }  
    }  
}

```

# Commit Final
Refactor: Improve UI consistency and splash screen implementation  
  
This commit introduces several UI enhancements and refactors the splash screen implementation.  
  
**Key Changes:**  
  
- **Splash Screen:**  
    - Added `androidx.core:core-splashscreen` dependency.  
    - Implemented a splash screen using `Theme.SplashScreen` in `themes.xml` and `installSplashScreen()` in `MainActivity`.  
    - Defined a custom splash theme `Theme.ExerLog.Splash`.  
- **Theme & Window Management:**  
    - `AppTheme`:  
        - Modified to handle status bar transparency and icon color based on the current theme (light/dark).  
        - Uses `WindowCompat.setDecorFitsSystemWindows(window, false)` to enable edge-to-edge content.  
    - `MainActivity`:  
        - Updated to correctly apply edge-to-edge display.  
        - Simplified status bar controller setup. Removed explicit hiding of system bars.  
        - Wrapped `AppNavHost` in a `Surface` to ensure proper background color application.  
- **UI Components:**  
    - `HeaderSession.kt`:  
        - Time text color now uses `MaterialTheme.colorScheme.primary`.  
    - `Home.kt`:  
        - Adjusted padding in `LazyColumn`.  
    - `SessionCard.kt`:  
        - Changed `shape` to `MaterialTheme.shapes.medium`.  
        - Reduced vertical padding.  
    - `Session.kt`:  
        - Wrapped content in a `Surface` to ensure the background color is applied correctly.  
        - Updated preview to `PreviewSessionScreenMock` with mock data for better visualization.  
- **Gradle:**  
    - Added `coreSplashScreen` version to `libs.versions.toml`.  
- **Manifest:**  
    - Set `android:launchMode="singleTop"` for `MainActivity`.  
    - Changed `MainActivity` theme to `Theme.ExerLog.Splash`.  
- **Deployment Target:**  
    - Updated deployment target selector in `.idea/deploymentTargetSelector.xml`.  
  
**Impact:**  
  
- Provides a more polished user experience with a proper splash screen.  
- Improves UI consistency with better theme application and edge-to-edge display.  
- Enhances the appearance of session cards and headers.
