# Flashcards - Tema 19: Arquitectura Java EE/Jakarta EE y .NET

## Jakarta EE

Jakarta EE (Java EE)::Conjunto de especificaciones para desarrollar aplicaciones Java empresariales multicapa

Relación Java EE con Java SE::Java EE es una plataforma extendida sobre Java SE; requiere Java SE instalado

NO es componente clave de Jakarta EE::Compiladores

Servidor Jakarta EE::Servidor de aplicaciones que implementa APIs Jakarta EE y proporciona servicios de capa web y negocio

## Componentes Jakarta EE

Servlet::Componente Java que se ejecuta en un servidor web y procesa peticiones HTTP

EJB (Enterprise JavaBeans) - paquete::javax.ejb (jakarta.ejb)

Bean de entidad (EJB)::Representa datos persistentes y el comportamiento de esos datos

## Persistencia (JPA)

JPA::Especificación estándar para mapeo objeto-relacional (ORM) en Java

Lenguaje de consulta de JPA::JPQL (Java Persistence Query Language)

## Seguridad

JAAS::Java Authentication and Authorization Service; estándar para autenticación y autorización

Autenticación en Jakarta EE::Validar la identidad del usuario

Autorización en Jakarta EE::Permitir acceso según privilegios/roles

## Spring Boot

Spring Boot::Plataforma para aplicaciones web autocontenidas que llevan embebido el contenedor de servlets

## .NET

.NET es::Marco multiplataforma, gratuito, de código abierto (Microsoft), soporta múltiples lenguajes

Los lenguajes .NET compilan a::CIL (Common Intermediate Language)

CLR::Common Language Runtime; máquina virtual de .NET (equivalente a JVM)

NuGet::Administrador de paquetes de .NET

ADO.NET - objeto NO existente::Operation (no existe en ADO.NET)

## ASP.NET Core

Razor (ASP.NET Core)::Sintaxis de plantillas para crear vistas dinámicas; usa @ para transición de C# a HTML

## Comparativa

Equivalente de JVM en .NET::CLR (Common Language Runtime)

Equivalente de JPA en .NET::Entity Framework Core

Equivalente de Maven en .NET::NuGet

Equivalente de JPQL en .NET::LINQ
