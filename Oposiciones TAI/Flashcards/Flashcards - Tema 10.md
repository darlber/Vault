## Arquitectura de ordenadores

Arquitectura Von Neumann - componentes CPU::ALU (UAL), Unidad de Control, Registros
<!--SR:!2026-06-16,3,250-->

Arquitectura Harvard - característica::Dos memorias separadas: una para instrucciones y otra para datos
<!--SR:!2026-06-16,3,250-->

Arquitectura Von Neumann vs Harvard::Von Neumann: bus único (cuello de botella); Harvard: memorias separadas, permite acceso simultáneo
<!--SR:!2026-06-16,3,250-->

Taxonomía Flynn - micros multinúcleo::MIMD (Multiple Instruction Multiple Data)
<!--SR:!2026-06-16,3,250-->

CISC vs RISC::CISC = conjunto complejo; RISC = conjunto reducido (opuesta a CISC)
<!--SR:!2026-06-16,3,250-->

CPU compuesta por::Registros, ALU y Unidad de Control

Unidad que supervisa transferencia e indica a ALU qué ejecutar::Unidad de Control (UC)

La BIOS se almacena en::ROM o memoria flash

Memoria de acceso más rápido::Caché

DIMM y SIMM::Tipos de encapsulado de memoria (Dual/Single In-line Memory Module)
