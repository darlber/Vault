# Flashcards - Tema 21: Aplicaciones Web, HTML, CSS, XML, Navegadores, Script

## HTML5

HTML es::Lenguaje de marcado (no de programación)

DOCTYPE HTML5::`<!DOCTYPE html>`

Etiquetas semánticas HTML5::`<article>`, `<aside>`, `<nav>`, `<section>`, `<header>`, `<footer>`, `<main>`

`<article>` en HTML5::Contenido independiente y reutilizable (post, noticia)

## CSS

CSS significa::Cascading Style Sheets

Objetivo fundamental de CSS::Separar el contenido HTML de su estilo de presentación

Selector de ID en CSS::`#` seguido del nombre

Selector de clase en CSS::`.` seguido del nombre

Pseudoclase hover::Selecciona elemento con el ratón encima

Propiedad para tamaño del texto::`font-size`

## XML

XML::Lenguaje estándar para intercambiar información entre plataformas

Documento XML bien formado::Cumple reglas sintácticas (etiquetas anidadas, raíz única, atributos entre comillas)

Documento XML válido::Bien formado + cumple un esquema (DTD o XSD)

DOM (parseo XML)::Carga todo el documento en memoria creando un árbol de nodos

SAX (parseo XML)::Parsing secuencial basado en eventos, no carga todo en memoria

XSLT::Lenguaje para transformar un documento XML en otro formato (HTML, texto, etc.)

## HTTP

Método HTTP idempotente y seguro::GET

Qué significa idempotente::Múltiples peticiones idénticas producen el mismo resultado

Qué significa seguro en HTTP::No modifica el estado del servidor (solo lectura)
