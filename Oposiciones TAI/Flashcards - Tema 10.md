# Flashcards - Tema 10: Informática Básica

## Sistema Informático

Sistema informático::Conjunto de hardware, software y recursos humanos

Objetivo del sistema informático::Procesar, almacenar y transmitir información

Componentes del sistema informático::Hardware, software, datos, procedimientos, personas

NO es componente::Electricidad

## Generaciones de ordenadores

Primera generación - componente::Válvulas de vacío

Segunda generación - componente::Transistores

Ley de Moore::El número de transistores se duplica aprox. cada 18 meses

## Arquitectura de ordenadores

Arquitectura Von Neumann - componentes CPU::ALU (UAL), Unidad de Control, Registros

Arquitectura Harvard - característica::Dos memorias separadas: una para instrucciones y otra para datos

Arquitectura Von Neumann vs Harvard::Von Neumann: bus único (cuello de botella); Harvard: memorias separadas, permite acceso simultáneo

Taxonomía Flynn - micros multinúcleo::MIMD (Multiple Instruction Multiple Data)

CISC vs RISC::CISC = conjunto complejo; RISC = conjunto reducido (opuesta a CISC)

## CPU y Memoria

CPU compuesta por::Registros, ALU y Unidad de Control

Unidad que supervisa transferencia e indica a ALU qué ejecutar::Unidad de Control (UC)

Función de la BIOS::Inicializar y testear hardware, cargar el sistema operativo

La BIOS se almacena en::ROM o memoria flash

Memoria de acceso más rápido::Caché

DIMM y SIMM::Tipos de encapsulado de memoria (Dual/Single In-line Memory Module)

Bus::Canal de comunicación entre componentes

## Unidades de información

Sistema binario - base::2

Bit::Valor 0 o 1 en binario; unidad mínima de información

Byte::8 bits

Orden de mayor a menor capacidad::Byte, Kilobyte, Megabyte, Gigabyte, Terabyte, Petabyte, Exabyte, Zettabyte, Yottabyte

Unidad para 10^24 Bytes::Yottabyte (YB)

## Medición rendimiento

FLOPS::Operaciones de coma flotante por segundo (mide potencia del microprocesador)

## E/S

DMA (Direct Memory Access)::Técnica de E/S que libera a la CPU durante transferencias
