**NIST Special Publication 800-53.** Es un **catálogo detallado de controles de seguridad y privacidad**, no un framework de alto nivel como el CSF. Creado para sistemas federales de EE. UU. (FISMA). Contiene **20+ familias de controles** (AC = Access Control, AU = Audit & Accountability, CM = Configuration Management, etc.). Cada control tiene declaración, parámetros y guías de implementación. La guía hermana **800-53A** define cómo evaluar cada control. No obligatorio para banca privada, pero se usa como **benchmark de mejores prácticas**. Para un IT auditor: cuando veas "NIST 800-53" piensa en una checklist detallada de controles técnicos.
