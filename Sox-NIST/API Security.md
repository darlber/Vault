**Protección de APIs REST/GraphQL.** Controles clave: (1) **autenticación** — JWT, OAuth2, API keys con rotación, (2) **autorización** — validar permisos en cada endpoint, no solo en la puerta, (3) **rate limiting** — prevenir abuso y DoS, (4) **validación de entrada** — sanitizar inputs para prevenir injection (SQLi, XSS), (5) **cifrado** — TLS obligatorio, (6) **logging** — registrar accesos a APIs para auditoría, (7) **OWASP API Security Top 10** — guía de referencia. En auditoría: se revisa que las APIs tengan autenticación, logging y rate limiting.
