**Seguridad integrada en pipelines CI/CD (Jenkins, GitHub Actions, GitLab CI).** Controles clave: (1) **secrets scanning** — detectar credenciales hardcodeadas en el código (git secrets, truffleHog), (2) **SAST** — análisis estático en cada commit (SonarQube, Checkmarx), (3) **SCA** — escaneo de dependencias vulnerables (Snyk, OWASP Dependency Check), (4) **firmado de artefactos** — garantizar integridad, (5) **aprobaciones** — gates humanos para despliegue a producción, (6) **hardening del pipeline** — quién puede modificar la pipeline. En auditoría: se revisa que los controles de seguridad estén automatizados y no sean saltables.
