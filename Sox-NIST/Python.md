**Lenguaje de programación multipropósito.** En auditoría TI se usa para: automatizar pruebas de controles (scripts que verifican configuraciones), analizar logs y eventos, conectar con APIs para extraer evidencia (ej: usuarios de Active Directory, reglas de firewall), y procesar datos con pandas. Bibliotecas clave: requests (APIs), paramiko (SSH), boto3 (AWS), openpyxl (Excel). Es el lenguaje más demandado hoy en IT audit por su versatilidad y baja curva de aprendizaje. Si sabes Python en una entrevista, puedes decir que automatizas pruebas de controles repetitivas.
