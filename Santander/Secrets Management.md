**Gestión segura de credenciales, tokens, API keys, certificados y otras secrets.** No se deben almacenar en código fuente, config files o variables de entorno sin cifrar. Herramientas: HashiCorp Vault, AWS Secrets Manager, Azure Key Vault, CyberArk. Prácticas: rotación automática, acceso just-in-time, auditoría de accesos a secrets. En auditoría se revisa: ¿hay un vault centralizado?, ¿las secrets se rotan periódicamente?, ¿hay logs de quién accede a qué secret?, ¿se hardcodean credenciales en pipelines CI/CD?
