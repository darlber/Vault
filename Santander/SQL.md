**Structured Query Language — lenguaje para consultar y manipular bases de datos.** Esencial en auditoría para: extraer muestras representativas de transacciones, analizar accesos a datos sensibles (SoD conflicts), identificar transacciones inusuales, y verificar integridad de datos. Comandos clave: SELECT, JOIN, GROUP BY, WHERE, subqueries. Se usa con Oracle, SQL Server, PostgreSQL, MySQL. En la entrevista: saber SQL demuestra que puedes hacer análisis de datos directamente, sin depender de nadie.
